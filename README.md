# Sky Grid Technical Services L.L.C. — Cloudflare Website

A responsive, static corporate website designed for Cloudflare Pages.

## Files
- `index.html` — website content
- `styles.css` — responsive design and layout
- `script.js` — mobile menu and form demo
- `assets/sky-grid-logo.png` — Sky Grid logo

## Before launch
Replace the placeholder phone number and email in `index.html` with the company's official contact details. Connect the enquiry form to a form/email provider if required.

## Cloudflare Pages
1. Create a GitHub repository and upload these files.
2. In Cloudflare, open **Workers & Pages** → **Create application** → **Pages** → **Connect to Git**.
3. Select the GitHub repository.
4. For this static site, leave the build command empty and use the repository root as the output directory.
5. Deploy.
6. Add your custom domain in Cloudflare Pages → Custom domains.

No traditional web hosting is required.
